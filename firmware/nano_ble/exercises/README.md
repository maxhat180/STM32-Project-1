# Nano learning exercises

Board: Arduino Nano 33 BLE Sense Rev2.

Each exercise has its own folder containing a sketch and short notes. Keep the
main sketch filename identical to the folder name, for example
`01_blink/01_blink.ino`.

| Exercise | Objective | Status |
| --- | --- | --- |
| [01_blink](01_blink/README.md) | Non-blocking LED timing and serial stop/resume | Manually verified by developer, October 26, 2026 |
| [02_accelerometer](02_accelerometer/README.md) | Initialize the onboard IMU, then acquire acceleration | Rate-limited X/Y/Z working per developer; static validation and timing cleanup next |

Add later exercises as you reach them. Record actual observations before marking
an exercise complete; saving or compiling a sketch does not verify the hardware.
